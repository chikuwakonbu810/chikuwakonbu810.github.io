プライバシーポリシー

課題ガジェット（以下「本アプリ」）が、利用者のデータをどのように扱うかを説明します。

1. 本アプリが読み取るデータ

利用者が許可した場合に限り、Google Classroomから次のデータを読み取り専用で取得します。

  • 参加している授業の名前
  • 授業に出された課題のタイトルと締切
  • 利用者自身の課題の提出状況（提出済みかどうか）

使用する権限（スコープ）は次の2つです。課題の作成・変更・提出など、書き込みの操作は一切行いません。

  • https://www.googleapis.com/auth/classroom.courses.readonly
  • https://www.googleapis.com/auth/classroom.coursework.me.readonly

2. データの使い道

取得したデータは、利用者のパソコンのデスクトップに、まだ提出していない課題と締切を表示するためだけに使います。

3. データの保存場所

  • 取得したデータは、利用者自身のパソコンの中にだけ保存されます
  • Googleとの連携に使う認証情報は、Windowsの暗号化機能で保護して保存します
  • 本アプリには開発者が運営するサーバーはなく、データが開発者に送られることはありません

4. 第三者への提供

取得したデータを第三者に提供・販売することはありません。広告や利用状況の分析にも使いません。

本アプリによるGoogle APIから受け取った情報の使用と移転は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

5. 連携の解除とデータの削除

  • 本アプリの設定欄の「解除」を押すと、Googleへの許可を取り消したうえで、認証情報と取り込んだ課題のデータをパソコンから削除します
  • Googleアカウントのサードパーティ製のアプリとサービスから、いつでも本アプリへの許可を取り消せます

6. Moodleのデータ

Moodleのカレンダーから取得する課題の情報も、Googleのデータと同じく利用者のパソコンの中でだけ扱い、外部には送りません。

7. お問い合わせ

本ポリシーについてのお問い合わせは、GitHubのIssuesからお願いします。

8. 改定

本ポリシーを変更する場合は、このページで公開します。

Summary (English)

Kadai Gadget accesses Google Classroom data (course names, coursework titles and due dates, and the user's own submission states) read-only, only after the user grants permission. The data is used solely to display unsubmitted assignments on the user's desktop, is stored only on the user's own computer, and is never sent to the developer or any third party. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Users can revoke access at any time from their Google Account.
